# Super WiFi Duck Pad

This is the firmware for [my keypad](https://github.com/gavhu10/keypad).
  
It is a fork of [wasdwasd0105/SuperWiFiDuck](https://github.com/wasdwasd0105/SuperWiFiDuck) which is a fork of [SpacehuhnTech/WiFiDuck](https://github.com/SpacehuhnTech/WiFiDuck).

It supports duckyscript to help you automate tasks. You can find the documentation [here](DUCKYSCRIPT.md).
